# 倍数・約数迷路

小学5年生向けの、倍数・約数を順番にたどる算数迷路です。

公開ページ： https://tt-sensei.github.io/bai-yaku-maze/

## あそび方

1. レベルを選び、「迷路をつくる」を押します。
2. 「倍数」「約数」「公倍数」「公約数」から迷路の種類を選びます。もとになる数は種類とレベルに合わせて毎回ランダムに決まります。
3. 倍数・約数は緑のスタートから、上下左右に隣り合うマスへ進みます。
4. 公倍数・公約数はA・Bの2つのスタートからそれぞれ進み、共通する数のマスで合流します。
5. ヒントには正解の数を表示せず、数のきまりを考えるための手がかりだけを表示します。

一度に進めるのは上下左右の隣のマスだけです。斜め移動はできません。間違えてもゲームオーバーにはならず、考え直して続けられます。「一つ戻る」で直前のマスへ戻ることもできます。

## 難易度

難易度は3段階です。盤面が広くなるだけでなく、倍数はたどる数の個数を増やし、約数は対象となる数を大きくして、道のりが長くなるようにしています。

| レベル | 盤面 | 倍数の道 | 約数の出題例 |
|---|---:|---:|---|
| レベル1 | 5×5 | 5個の倍数 | 12、18、20、24、30 |
| レベル2 | 7×7 | 10個の倍数 | 60、72、84、90、120、180 |
| レベル3 | 9×9 | 16個の倍数 | 240、360、420、480、540、600、720、840 |

倍数の道は、対象の数の最初の正の倍数から、同じ数ずつ増える順番です。約数の道は、対象の数の正の約数を小さい順にすべてたどります。公倍数の迷路は2つの数からそれぞれの倍数をたどり、最小公倍数で合流して、さらに共通の倍数へ進みます。公約数の迷路は2つの数からそれぞれの約数を大きい順にたどり、共通する約数で合流した後、共通の約数を順にたどります。レベルが上がると道のりや対象となる数が大きくなります。盤面の数字の範囲は、選ばれた問題の最大の数に合わせて広がります。

## 迷路生成

- 正解ルートを先に作り、ルートに沿って数字を配置します。
- 残りのマスに数字をランダムに配置します。
- 各段階で正しい次の数へ進む道が一つだけになるよう、生成後に検査します。
- ランダム配置で条件を満たせない場合は、別解ができない安全な数字配置に切り替えます。
- 迷路を作るたびに盤面・出題種別・対象の数が変わります。

## 公倍数・公約数の合流迷路

- A・Bの2つのスタートを設け、それぞれの数のきまりに沿った道をたどります。
- 公倍数は最小公倍数、公約数は最大公約数で合流し、そこから共通する数をたどります。
- 生成後に、それぞれの道で次の数へ進める候補が一つだけになるか検査します。
- 合流するマスはA・Bどちらの道でも進めるようにし、両方が合流点まで来ると共通の道が完成します。
