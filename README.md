# 倍数・約数迷路

数字を見て、倍数・約数を判断しながら、ナビキャラクターと4方向の道を進む算数ミニゲームです。

## 現在のプロトタイプ

- 倍数モード：「○の倍数を進もう！」
- 約数モード：「○の約数を進もう！」
- 上下左右に最大4つの数字を表示
- 正解の数字は最低1つ必ず出現
- 正解と方向の対応を保証
- 正解タップで1マス進む
- 不正解でもライフ減少・ゲームオーバーなし
- 12ポイントでゴール
- 正解数・まちがい数・クリアタイムを表示
- ナビキャラクター6人から選択
- ナビキャラクター画像を利用
- クリア時にモード別の初回クリアバッジを記録（localStorage）
- タブレット優先のレスポンシブUI
- キーボードの矢印キーにも対応

## 設計方針

このゲームは「4方向の数字を見て、条件に合う道を選ぶ」ことを迷路として体験できる構成です。

公倍数・公約数、ライフ、コンボ、アイテム、ショップ、複雑な演出などは入れていません。
