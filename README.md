# 倍数・約数迷路

数字を見て、倍数・約数を判断しながら、ナビキャラクターと4方向の道を進む算数ミニゲームです。

## 現在のプロトタイプ

- 倍数モード：「○の倍数を進もう！」
- 約数モード：「○の約数を進もう！」
- 上下左右に最大4つの数字を表示
- 正解の数字は最低1つ必ず出現
- 正解をタップするとその方向へ進む
- 不正解でもライフ減少・ゲームオーバーなし
- 10マスでゴール
- 正解数・まちがい数・クリアタイムを表示
- ナビキャラクター6人からランダム選択
- ナビキャラクターの正解・リトライ・クリア画像を利用
- クリア時にモード別の初回クリアバッジを記録（localStorage）
- タブレット優先のレスポンシブUI
- キーボードの矢印キーにも対応

## 設計方針

このゲームは「本格的な固定迷路」ではなく、「4方向の数字を見て、条件に合う道を選ぶ」ことを迷路として体験できる構成です。

公倍数・公約数、ライフ、コンボ、アイテム、ショップ、複雑な演出などは入れていません。

## アセット

ナビキャラクターは `TT-sensei/navi-character-` の公開アセットをCDN形式で参照しています。

本リポジトリはプロトタイプとして単一HTMLで動作します。今後、共通のedu-kit / edu-effects / バッジ基盤へ接続する場合も、ゲームロジックとUIの責務が分離しやすい構成にしています。
