# 倍数・約数迷路

小学5年生向けの、倍数・約数を順番にたどる算数迷路です。

公開ページ： https://tt-sensei.github.io/bai-yaku-maze/

## あそび方

1. 「倍数の迷路」または「約数の迷路」を選びます。
2. 倍数・約数の対象となる数を選びます。
3. レベルを選び、「迷路をつくる」を押します。
4. 緑のスタートから、上下左右に隣り合うマスへ進みます。
5. 倍数は小さい順、約数も小さい順にたどって、オレンジのゴールを目指します。

一度に進めるのは上下左右の隣のマスだけです。斜め移動はできません。間違えてもゲームオーバーにはならず、考え直して続けられます。

## 難易度

| レベル | 盤面 | 数字の範囲 | ねらい |
|---|---:|---:|---|
| レベル1 | 5×5 | 1〜72 | 数の順番を確かめる |
| レベル2 | 7×7 | 1〜84 | 次の数を考えながら進む |
| レベル3 | 9×9 | 1〜108 | 広い盤面で順番を追う |
| レベル4 | 10×10 | 1〜120 | 広い迷路に挑戦する |

約数の迷路では、選んだ数の正の約数を小さい順にたどります。倍数の迷路では、選んだ数の最初の正の倍数から、同じ数ずつ増える順番でたどります。

## 迷路生成

- 正解ルートを先に作り、ルートに沿って数字を配置します。
- 残りのマスに数字をランダムに配置します。
- 生成後にルート探索を行い、ルールを満たすスタートからゴールまでの道が一つだけになる盤面を採用します。
- ランダム配置で一意なルートが作れない場合は、安全な数字配置に切り替えて、別解が生まれないようにします。
- 迷路を作るたびに盤面が変わります。

- GitHub Pages で動作します。
