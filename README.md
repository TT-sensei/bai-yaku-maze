# 倍数・約数迷路

小学5年生の「倍数・約数」と「公倍数・公約数」を、数字の迷路を進みながら練習する算数教材です。

公開ページ： https://tt-sensei.github.io/bai-yaku-maze/

## この教材でできること

- 「倍数」「約数」「公倍数」「公約数」の4種類から問題を選べます。
- 3段階のレベルから難しさを選べます。
- 上下左右に隣り合うマスだけをタップして進みます。斜めには進めません。
- 倍数・約数では1つのスタートから、公倍数・公約数ではA・Bの2つのスタートから進みます。
- 公倍数・公約数では、2つの道が共通する数で合流します。Aの道は赤、Bの道は青、両方が通った道は紫で表示されます。
- 通ったマスが色で残るので、これまでの道筋を確認できます。
- 間違えたときは、数のきまりを考え直して再挑戦できます。「一つ戻る」で直前のマスへ戻ることもできます。
- ヒント欄にはナビキャラがランダムに登場します。名前は表示せず、正解の数も直接は表示しません。

## あそび方

1. 迷路の種類を選びます。
2. レベル1〜3を選び、「迷路をつくる」を押します。
3. スタートのマスを確認し、次に来る数を考えます。
4. 今いるマスの上下左右から、数のきまりに合うマスをタップします。
5. 倍数・約数は順番に道をつなぎます。公倍数・公約数はAとBの両方の道を進め、共通する数で合流してゴールを目指します。
6. ゴールすると、進んだマス数、考え直した回数、かかった時間を確認できます。

正しい次の数そのものをヒント欄に表示するのではなく、学習者が数のきまりを思い出して判断する構成です。間違えても、その場で考え直して続けられます。

## レベルと出題範囲

| レベル | 盤面 | 倍数の道 | 約数の出題対象 |
| --- | --- | --- | --- |
| レベル1 | 5×5 | 10個の倍数 | 24、30、36、40、48、60 |
| レベル2 | 7×7 | 16個の倍数 | 60、72、84、90、120、180 |
| レベル3 | 9×9 | 24個の倍数 | 240、360、420、480、540、600、720、840 |

問題を作るたびに、対象となる数や盤面上の道筋が変わります。

- **倍数：** 選ばれた数の正の倍数を、小さい方から順にたどります。
- **約数：** 選ばれた数の正の約数を、小さい方から順にたどります。
- **公倍数：** A・Bそれぞれの倍数をたどり、最小公倍数で合流した後、共通する倍数を順にたどります。レベルが上がると、合流後にたどる共通の倍数が増えます。
- **公約数：** A・Bそれぞれの約数を大きい方からたどり、最大公約数で合流した後、共通する約数を順にたどります。

公倍数・公約数では、AとBの両方の道が正しくつながるように迷路を生成時に検査します。通常の倍数・約数でも、正しい次の数へ進む道が一つになるように検査し、条件を満たす配置を作れない場合は安全な数字配置に切り替えます。

## ナビキャラ

ヒント欄には、ナビキャラ共通素材集の6人（りく・そら・かい・さく・つき・なみ）から1人がランダムに表示されます。新しい迷路を始めるたびに選び直します。名前は画面に表示せず、学習の主役である問題や迷路を邪魔しない大きさにしています。

画像は共通素材集のWeb用WebPを参照しています。

- 素材集： https://tt-sensei.github.io/navi-character-/
- 画像パス： `assets/web/characters/{character-id}/fullbody/hint.webp`

そのため、迷路のゲーム処理はブラウザ内で動きますが、ナビキャラ画像の表示にはインターネット接続が必要です。画像を読み込めない環境では、キャラクターが表示されない場合があります。

## 技術・プライバシー

- HTML / CSS / JavaScript で作られた静的サイトです。
- GitHub Pagesで公開しています。
- バックエンド、データベース、APIキー、外部APIは使用しません。
- 問題生成、正誤判定、迷路の進行はブラウザ内で処理します。
- 学習履歴や個人情報をサーバーへ送信する仕組みはありません。
- 外部素材への依存はナビキャラ画像のみです。画像以外のゲーム機能は、外部APIに依存しません。
- タブレットでのタップ操作を想定し、画面幅に応じてレイアウトが変わります。
